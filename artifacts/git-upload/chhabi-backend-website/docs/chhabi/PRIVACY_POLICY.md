# Geeta Forgetech Privacy Policy

Effective date: 2 August 2026

Geeta Forgetech, operated by Chhabi, uses this HRMS to manage employee identity, attendance, payroll, leave, performance, meetings, chat, captions, recordings, biometric-device references, face-detection configuration and geo-fencing records.

Data is processed only for authorised workforce-management and security purposes. Access is role-based and activity may be audited. Meeting recording, camera, microphone, face detection, biometric attendance and location collection must be enabled only with applicable employee notice, consent and local-law compliance.

Recordings are stored in the deployment media storage. Administrators must define retention periods, restrict exports and delete data when it is no longer required. Users may request access, correction or deletion where applicable by contacting the Geeta Forgetech administrator.

The organisation must protect production access with HTTPS, strong passwords, backups and least-privilege permissions. External providers such as Zoom, Google and Microsoft process data under their own terms when configured.

Privacy contact: the designated Geeta Forgetech administrator.
