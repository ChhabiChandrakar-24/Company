# Geeta Forgetech Security Policy

This deployment is maintained by Chhabi for Geeta Forgetech.

- Use unique accounts and change all initial passwords before production use.
- Restrict Admin, HR and Manager permissions to authorised personnel.
- Use HTTPS and a TURN service for internet-facing internal calls.
- Protect MySQL, media recordings, OAuth tokens and backups from public access.
- Review audit logs and remove inactive accounts regularly.
- Do not share biometric, face, location or meeting-recording data outside approved business purposes.
- Revoke provider tokens immediately after suspected exposure.

Security issues should be reported privately to the designated Geeta Forgetech administrator. Do not publish credentials or employee data in public issue trackers.
