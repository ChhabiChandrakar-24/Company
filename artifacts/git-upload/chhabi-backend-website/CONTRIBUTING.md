# Contributing to Chhabi HRMS

Changes to this Geeta Forgetech deployment are maintained by Chhabi. Before submitting a change:

1. Do not commit credentials, employee records, recordings or provider tokens.
2. Preserve MySQL migration compatibility and the upstream open-source licence.
3. Run Django checks and relevant tests.
4. Document security, permission and data-retention impact.
5. Follow the Geeta Forgetech brand guide in `docs/chhabi/BRAND_GUIDE.md`.

The preserved upstream contribution guide is at [docs/upstream/CONTRIBUTING.md](docs/upstream/CONTRIBUTING.md).
