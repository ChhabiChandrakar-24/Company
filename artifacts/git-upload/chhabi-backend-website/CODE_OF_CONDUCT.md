# Chhabi / Geeta Forgetech Code of Conduct

All users and contributors must communicate respectfully, protect confidential workforce data and avoid harassment, discrimination, unauthorised surveillance or misuse of administrative access.

Concerns should be reported privately to the designated Geeta Forgetech administrator. Good-faith reports will be reviewed fairly and confidentially.

The preserved upstream community document is available at [docs/upstream/CODE_OF_CONDUCT.md](docs/upstream/CODE_OF_CONDUCT.md).
