# Chhabi HRMS Security Policy

Chhabi maintains this Geeta Forgetech deployment. Report vulnerabilities privately to the designated Geeta Forgetech administrator and never include employee data, credentials, OAuth tokens or recordings in a public report.

Production requirements include HTTPS, least-privilege roles, strong unique passwords, protected MySQL/media backups, regular audit review and timely dependency updates. Camera, microphone, recording, biometric, face and location features must follow applicable consent and retention rules.

Detailed deployment policy: [docs/chhabi/SECURITY_POLICY.md](docs/chhabi/SECURITY_POLICY.md).

The preserved upstream security document is available at [docs/upstream/SECURITY.md](docs/upstream/SECURITY.md).
