📚 Public REST API Reference

Use these endpoints in your mobile app, backend server, LMS, CRM, or website to create and control video meetings.

POST {{ base_api_url }}meetings/create/

Creates a new video room and returns direct join links for Host and Guest with signed tokens.

curl -X POST {{ base_api_url }}meetings/create/ \ -H "Content-Type: application/json" \ -H "X-API-Key: YOUR_API_KEY" \ -H "X-API-Secret: YOUR_API_SECRET" \ -d '{ "title": "Doctor Consultation Call", "host_name": "Dr. Ramesh (Host)", "guest_name": "Patient Amit", "allow_recording": true, "allow_chat": true, "allow_captions": true }'
import requests url = "{{ base_api_url }}meetings/create/" headers = { "X-API-Key": "YOUR_API_KEY", "X-API-Secret": "YOUR_API_SECRET", "Content-Type": "application/json" } payload = { "title": "Doctor Consultation Call", "host_name": "Dr. Ramesh", "guest_name": "Patient Amit" } response = requests.post(url, json=payload, headers=headers) data = response.json() print("Host Join URL:", data["join_url_host"]) print("Patient Join URL:", data["join_url_participant"])
const response = await fetch("{{ base_api_url }}meetings/create/", { method: "POST", headers: { "Content-Type": "application/json", "X-API-Key": "YOUR_API_KEY", "X-API-Secret": "YOUR_API_SECRET" }, body: JSON.stringify({ title: "Doctor Consultation Call", host_name: "Dr. Ramesh", guest_name: "Patient Amit" }) }); const meeting = await response.json(); console.log("Guest Join Link:", meeting.join_url_participant);
POST {{ base_api_url }}meetings/{id}/join-token/

Generates a new secure signed token and direct join URL for an extra attendee without requiring login.

curl -X POST {{ base_api_url }}meetings/101/join-token/ \ -H "Content-Type: application/json" \ -H "X-API-Key: YOUR_API_KEY" \ -d '{ "guest_name": "Sita Sharma", "guest_email": "sita@example.com", "guest_role": "participant", "expiry_hours": 48 }'
GET {{ base_api_url }}meetings/{id}/recordings/

Lists and downloads all recorded video files (.webm) for a specific meeting.

curl -X GET {{ base_api_url }}meetings/101/recordings/ \ -H "X-API-Key: YOUR_API_KEY"
